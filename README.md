Website description, capabilities, and Functions:

NurturePath Lactation Services is a hybrid e-commerce and booking platform featuring the following core functionalities:

Service & Product Catalog: Users can browse and select physical nursing supplies or book professional BSN-RN lactation consultations.

Dynamic Smart Cart: A persistent sidebar cart that allows users to add/remove items, adjust quantities, and calculate real-time totals using LocalStorage.

Live Inventory Management: Tracks item stock dynamically, automatically updating available quantities and preventing users from adding out-of-stock items.

Checkout & Order Processing: Features a checkout form with input validation for shipping and payment, coupon code application (e.g., "NURTURE20"), and order confirmation handling.

Functional Contact Form: Validates user inputs and routes inquiries directly to a specified email address using Formspree.

Resource Library: Provides downloadable educational PDF brochures for expecting and nursing mothers.

Network Telemetry: A diagnostic page that detects and displays local connection data (host, port, protocol) and last launch time.
